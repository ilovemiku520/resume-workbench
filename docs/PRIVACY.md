# 隐私说明

默认简历与预览截图只含通用占位词，没有预填姓名、联系方式、单位或经历；测试使用专门的虚构输入。运行服务的管理员与模型提供方是实际数据处理方；请结合自己的部署方式阅读以下说明。

| 操作 | 数据流向与保存 |
|---|---|
| 独立网页手动编辑 | 当前浏览器 localStorage；不发送服务器 |
| 上传 JSON 简历或模板 | 浏览器解析；模板严格限制样式字段，不执行代码 |
| 上传 PDF / PNG / JPEG 模板参考 | 浏览器内存中解析或渲染；刷新或删除参考后消失 |
| AI 改写 | 当前简历、要求、可选页面 API Key 发往当前服务器，再发 OpenAI |
| AI 提取风格 | 参考图像发往当前服务器及 OpenAI；图片内可见的个人信息也会发送 |
| MCP 工具调用 | 输入经宿主发送到 MCP 服务，结果回到宿主；本站不存档 |
| 内嵌 UI 同步 | 用户主动点击后，当前数据发送给宿主模型上下文 / 对话 |
| PDF / JSON / Markdown 导出 | 保存在使用者选择的本地位置 |

浏览器草稿不加密。共享设备、浏览器扩展及同源脚本可能访问 localStorage。清除站点数据可以删除草稿；JSON 导出文件也含个人信息，不应上传到公开仓库。

API Key 和服务令牌只保存在当前页面内存，不进入草稿、备份或 localStorage。关闭/刷新页面后需要重填。使用自己的服务器或可信部署，因为服务端仍能接收到这些密钥。服务端 `.env` 必须保密。

“隐藏姓名与联系方式”会移除基本信息中的姓名、邮箱、电话、位置、个人主页，以及正文中完全相同的文字；同时不向 API/宿主同步项目 URL。它不是完整的个人信息识别系统。经历描述、编辑要求、文件名、截图与其他自由文本仍可能识别个人。发送前自行检查；不要发送不必要的敏感内容。

源码后端没有简历数据库，也不记录请求正文和模型原始错误；不存在跨用户的可读取简历 ID。OpenAI 请求设置 `store:false`，但不等同于所有基础设施零保留。托管平台、反向代理、OpenAI 与 ChatGPT 各有数据规则。部署者必须审查相关配置，不承诺未经验证的端到端保密。

未集成分析 SDK、广告或遥测。README 的远程徽章是 GitHub 文档中的外部图片，不嵌入应用界面。
